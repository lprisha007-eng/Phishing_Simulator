# Phishing Awareness Simulator

## About
A simple interactive web-based phishing awareness simulator designed to help users recognize suspicious emails and understand common phishing techniques.

## Features
- Simulated email examples.
- Helps users identify suspicious email indicators.
- Demonstrates common phishing tactics.
- Interactive learning experience.
- Promotes cybersecurity awareness.

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open `phishing_simulator.html` in a web browser.
3. Explore the simulated emails and learn to identify potential phishing indicators.

## Purpose
This project was created to improve awareness of phishing attacks and help users develop safer email and internet habits.

## Disclaimer
This is a safe educational simulation. It is not designed to send real emails, conduct phishing attacks, or collect real credentials.
